# Juno Studio 1.4.1 — montage vidéo

Dans la timeline, les titres et éléments graphiques sont au-dessus des pistes image V1 à V10 ; les pistes son A1 et A2 restent en dessous. Cliquez sur **Piste image** pour créer V2, V3, etc. Déposez un plan sur une piste image existante pour remplacer uniquement le passage couvert sur cette piste ; les morceaux visibles de part et d’autre sont conservés. La piste voisine reste intacte. Les pistes verrouillées refusent les modifications.

Glissez le corps d’un plan pour le déplacer, ses bords pour le raccourcir et les petits cercles de ses coins supérieurs pour régler les fondus d’entrée et de sortie. Sur un plan audio, glissez la ligne horizontale vers le haut ou le bas pour ajuster le volume. Déplacez et allongez les titres graphiques avec les mêmes gestes. Glissez la règle ou la tête de lecture pour parcourir le film. Un clic sur un plan ouvre ses réglages ; le glisser ne les ouvre plus.

Le bouton **Avant / après couleur** dans la barre du moniteur compare le rendu du plan à son image d’origine sans modifier le montage. Le bouton en haut à droite du moniteur l’agrandit ; Échap le ferme. Le choix **Vertical · 1080p / 4K** précède **Version verticale**.

Dans **Texte & IA**, sélectionnez la langue de la source, puis relancez la transcription si nécessaire. Le français est proposé par défaut. La transcription locale utilise Whisper small dans cette version ; elle reste à relire, notamment pour les noms propres, voix simultanées et enregistrements bruyants. Une transcription modifiée manuellement n’est pas écrasée automatiquement.

Les originaux restent dans leur emplacement initial. Juno enregistre les changements de séquence localement et conserve l’annulation.
